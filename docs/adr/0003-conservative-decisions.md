# ADR 0003 — Explainable, conservative item decisions

Status: accepted, 2026-10-13.

An item receives structured active/future matches, a verdict, reasons and limitations. Affix labels/aliases match exactly after punctuation/case normalization. Unknown text is retained. Roll targets are unit-aware. Low recognition confidence, unknown slots, missing builds, unrecognized unique value or incomplete guide coverage prevent a discard suggestion. Equipped comparisons may identify an upgrade candidate only when primary rolls are comparable and no known power is lost; this is not a damage simulation.

Transitions require explicit prerequisites plus acceptance. Level alone never silently switches builds. Skill and Paragon recommendations read only supplied sequences, with no generated allocations or invented routing.
